# Vento Systems Hyderabad preview

This is an independent prototype for the offshore engineering and Global Capability Center section. Its navigation follows the separate visual reference’s service-led structure, using Vento’s palette, typography, artwork and project examples. The corporate site files are outside this preview.

## Run locally

Use Node.js 20 or later. From the repository root:

```sh
node vento-hyderabad-preview/server.mjs
```

Open [the homepage](http://127.0.0.1:8774/). The preview includes Engagement Models, How We Work, Capabilities, Hyderabad and Contact. Pass a port as the last argument to use a different port.

The contact form prepares a draft in the browser. The visitor sends it from their own email app.
