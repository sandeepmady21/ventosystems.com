Selected work/Perception & control

Engineering note / 02

Between a signal and a movement.

Our lab work includes a camera-guided mobile robot and controller firmware for a sit-to-stand walker. They are separate projects with a shared question: how do inputs become understandable, controlled behaviour?

Application
Physical systems
Work
Lab prototype and controller firmware
Connection
Perception, embedded software and control

The engineering focus

Understand the whole path from an input to the behaviour it produces.

Vento Autonomy →

Two projects, different control problems.

The mobile-robot prototype connects camera input, navigation and control at a small scale. It provides a setting for investigating how a machine interprets its surroundings and turns that information into movement.

The walker work is controller firmware. Its focus is the relationship between inputs, embedded logic and the machine’s response, with the person using it central to the problem.

Both projects are at the lab stage, bringing different settings to the study of perception and control.

The parts have to work together.

Perception, embedded software and control need to be considered as a connected system. An uncertain observation can affect a decision. A delayed input can affect a response. The operator also needs to understand what the machine is doing.

This makes the interface between disciplines a useful place to investigate. The functional views above make the relationships between observation, embedded logic and physical response explicit.

Questions for the next evaluation

A next investigation would define a specific task and test conditions around these questions.

Observation

What can the system infer from an input under the conditions of the task? Which uncertain or missing observations need a different response?

Response

How do commands translate into behaviour, including when an input is delayed or absent? What operating limits should the test make explicit?

Supervision

How will the person overseeing a trial understand the current state, recognise a problem and intervene? What should be recorded for review?
