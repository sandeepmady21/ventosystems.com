Security testing, compliance readiness and incident response for applications, cloud and infrastructure. Delivered with a specialist security partner, with Vento Systems as your point of contact.

What we cover

Four areas, from a single test to ongoing monitoring.

01

Application security testing

Find the weaknesses in what your customers and staff use, before someone else does.

  • Web application penetration testing, against OWASP Top 10 and ASVS
  • Mobile apps on iOS and Android
  • APIs, including authentication and access control
  • Desktop (thick-client) applications
  • Secure code review
  • Database security review
02

Infrastructure and cloud

Check the networks, servers and cloud accounts everything runs on.

  • Network and host penetration testing
  • Cloud configuration review and hardening for AWS, Azure and Google Cloud
  • Wireless network assessment
  • IoT and device security, including firmware
  • Industrial and OT systems, against IEC 62443
03

Threat testing and response

Test how your people and defenses hold up, and get help when something happens.

  • Red team exercises
  • Phishing and social-engineering simulation
  • Continuous vulnerability management
  • Threat monitoring
  • Managed detection and response, around the clock
  • Incident response and digital forensics
04

Compliance readiness

Get ready for an audit or a customer review, with the evidence in order.

  • SOC 2 Type I and Type II
  • ISO/IEC 27001 and 27701
  • PCI DSS 4.0
  • HIPAA
  • NIST Cybersecurity Framework 2.0
  • GDPR
  • Customer security questionnaires
  • Vendor risk reviews
  • Security policies and an information security management system
  • In India: CERT-In security audits, carried out with a CERT-In empanelled auditor
  • In India: the RBI cybersecurity framework for banks and NBFCs

Common starting points

Most engagements begin with one of these.

  • Before a launchA penetration test of a new app or API, with fixes retested before go-live.
  • A first SOC 2 auditA gap assessment, the policies and controls you are missing, and help gathering evidence.
  • A customer security reviewAnswers to a security questionnaire, backed by a recent test and your policies.
  • After a cloud moveA configuration review of the new accounts, with a hardening plan.
  • Something has happenedContainment, investigation and recovery, with evidence handled for later review.

How an engagement runs

The same four steps for a single test or a compliance program.

  1. 01ScopeWhat is in scope, how testing may run, the test windows and who to call if something breaks.
  2. 02TestManual testing by specialists, supported by automated tools, within the agreed rules.
  3. 03ReportEach finding with its evidence, severity and fix, plus a summary for leadership.
  4. 04RetestFixed findings are tested again to confirm they are closed.
