Current prototypes

Two prototypes that investigate different parts of a machine system.

Lab prototype · Perception and navigation

Camera-guided mobile robot

Camera input, navigation and control in one small-scale system, for studying how observations inform movement decisions.

Research question
How should uncertainty in camera observations affect a movement decision?
Next experiment
Compare observations, control commands and actual motion on a defined route as conditions change.

Lab prototype · Embedded control

Sit-to-stand walker firmware

Controller firmware for a sit-to-stand walker, linking inputs, control commands and machine state, and how that state is shown to the person using it.

Research question
How should the controller respond when an input changes, arrives late or is absent?
Next experiment
A bench setup with simulated inputs to compare expected commands and state changes, including stop conditions.

Applications

Research directions. Requirements and validation are established for each setting.

Haulage and fixed routes

Perception and collision warning for vehicles in controlled operating areas, with any further automation developed through staged evaluation.

Warehouse movement

Sensing and control for repetitive material movement, including how a system responds around people and changing obstacles.

Repetitive site tasks

Tasks such as marking out and moving material, where a constrained first application makes the work measurable.

Testing approach

A collaboration starts with a defined machine task, operating conditions and test scope.

  1. 01PerceptionCompare sensor observations with what is actually happening, including missed detections and changing conditions.
  2. 02Embedded controlTrace how inputs become commands, define operating limits and test delayed or missing information.
  3. 03Operator interfaceMake the machine’s state and intended action clear, with supervision and stop conditions.
