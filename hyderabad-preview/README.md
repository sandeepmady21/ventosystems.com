# Vento Systems Hyderabad preview

Unlisted preview of the offshore engineering and Global Capability Center pages, served at
https://ventosystems.com/hyderabad-preview/. Nothing on the main site links here; every page carries
`noindex, nofollow` and robots.txt disallows the folder.

These are plain static pages (header, footer and enquiry form already written into each page), built
from Codex branch `codex/vento-hyderabad-preview`. Site-wide artwork and `company.css` come from
`/assets/`. To view locally, serve the repository root with any static server and open
`/hyderabad-preview/`.

The contact form prepares a draft in the browser. The visitor sends it from their own email app.
