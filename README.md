# ventosystems.com

The Vento Systems website. One self-contained page — no framework, no build step.

- `index.html` — the whole site (HTML, CSS and JS in one file; fonts from Google Fonts)
- `CNAME` — custom domain for GitHub Pages
- `404.html` — sends unknown paths back to the homepage
- `.nojekyll` — tells GitHub Pages to serve the files as they are

Deploys automatically from the `main` branch via GitHub Pages.
